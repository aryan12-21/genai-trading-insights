# GenAI Power Trading Insights Assistant

A Python assistant for questions about synthetic Indian electricity market data. It uses a LangChain tool-calling agent with Groq's Llama model, a locally generated embedding index, and tools for structured data lookups, on-demand trend charts, and domain-term retrieval.

## Features

- Looks up MCP, ACP, and on-bar statistics from the project's CSV using pandas.
- Retrieves glossary entries and generated daily summaries from a small NumPy cosine-similarity vector store.
- Creates trend charts when requested.
- Provides a Streamlit chat interface and a FastAPI backend (`GET /health` and `POST /ask`).

The CSV is generated by `data/generate_data.py`; it is synthetic demo data, not live market data or NLC/SRLDC/IEX operational data. Numerical answers describe that sample dataset only.

## Requirements and setup

Python 3.11 or newer is recommended. Install dependencies in a virtual environment:

```sh
python -m venv .venv
```

Activate it, then run:

```sh
python -m pip install -r requirements.txt
```

Copy `.env.example` to `.env` and set your own Groq API key in `.env`. Never commit `.env` or share its key. `GROQ_MODEL` is optional; the default is `llama-3.3-70b-versatile`.

Generate the dataset and vector store:

```sh
python data/generate_data.py
python -c "from app.rag_store import build_vectorstore; build_vectorstore('data/market_data.csv')"
```

The embedding model is downloaded for local use on first setup. The vector store is a generated local artifact and is ignored by Git.

## Run the app

Streamlit chat interface:

```sh
streamlit run streamlit_app.py
```

FastAPI backend:

```sh
uvicorn app.main:app --reload
```

Send a question to `POST /ask` as JSON, for example:

```json
{"question":"What was the average MCP for NLCIIST2 in DAM on 2026-08-01?"}
```

The repository includes a Dockerfile for the FastAPI service. It currently generates the CSV but does not build the required vector store; because \`vector_store.pkl\` is ignored by Git, add a vector-store build step to the image process before running the container.

## Main components

- `app/agent.py` — Groq LLM setup, prompt, and tool-calling agent.
- `app/query_tool.py` — pandas-based market data queries.
- `app/chart_tool.py` — trend chart generation.
- `app/rag_store.py` — glossary/daily summaries, embeddings, and local vector search.
- `app/main.py` — FastAPI endpoints.
- `streamlit_app.py` — interactive chat UI.
- `data/generate_data.py` — synthetic sample data generator.

## Configuration

Required: `GROQ_API_KEY`. Optional: `GROQ_MODEL`. Keep API keys in an untracked `.env` file or environment variables, never in source control.
